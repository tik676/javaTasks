## 🛠 Запуск и компиляция проектов

Из-за особенностей работы с кодировками (кириллица в консоли) и версиями Java, файлы необходимо компилировать вручную перед запуском. 

Выполните следующие шаги в терминале (PowerShell / CMD):

Сначала нужно скомпилировать `.java` файл в байт-код `.class`, явно указав кодировку UTF-8, чтобы избежать проблем с кириллицей:
`javac -encoding UTF-8 Main.java`

Далее установить версию соответствующую версии на пк пример: `javac -encoding UTF-8 --release 8 Main.java`

И уже запустить непосредственно задание
`java Main`
